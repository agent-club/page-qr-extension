## 简短说明

一键生成当前网页二维码。自定义内容、颜色和尺寸，本地离线生成，下载 PNG 或 SVG。

## 详细说明

页码让你把电脑上的网页轻松带到手机：点击工具栏图标，当前网页的二维码就会自动出现。

你可以：

- 将当前网页的完整网址生成二维码，保留查询参数与页面片段。
- 修改二维码内容，支持网址、中文、多行文字和特殊字符。
- 自定义前景色、背景色，以及 256–2048 像素的输出尺寸。
- 实时预览，随时恢复当前网址。
- 下载 PNG 位图或 SVG 矢量图。
- 在本机记住颜色和尺寸，下次打开直接使用。

所有二维码都在浏览器本地生成。插件仅在点击时读取当前活动标签页，用于二维码功能；不会将网址、二维码内容或浏览历史上传给开发者或远程服务。只有颜色与尺寸会保存在本机，网址与输入内容不会被持久保存。无账号、无广告追踪、无远程执行代码。

二维码最多支持 2331 字节；中文和特殊字符可能占用多个字节。颜色对比度低或内容较长时，插件会给出扫码建议。浏览器内部页和本地文件不会自动生成普通网页网址二维码，你仍可手动输入内容。

问题反馈及源码可在项目 GitHub 页面查看。

## 单一用途

将用户主动打开的当前网页网址或用户自行输入的内容，在浏览器本地生成可自定义配色和尺寸的二维码，并下载 PNG／SVG 图片。

## 权限理由

### activeTab

仅在用户点击插件工具栏图标时读取当前活动标签页的 URL，将其显示在弹窗内并生成二维码。不访问后台标签页、不读取页面正文、不注入脚本，也不持续追踪浏览活动。

### storage

仅使用 chrome.storage.local 保存前景色、背景色和输出尺寸。保存对象为 appearance；不保存 URL、二维码内容或浏览历史，不使用同步存储。

### 远程代码

选择“不使用远程代码”。二维码生成库随插件本地打包，Manifest V3 内容安全策略禁止网络连接，没有 CDN 脚本或远程执行代码。

## 数据使用披露

插件在本地访问当前标签页 URL，并处理用户主动输入的内容，这是已明确披露的核心功能。开发者不收集或接收这些内容，不向第三方传输。只有外观设置保存在用户设备上。

填写控制台时按其当时的字段定义作答：如果字段询问开发者是否收集或传输用户数据，按本插件“无服务端收集／无传输”的实际行为填报；如果字段询问扩展是否访问或处理网址、网站内容等数据，应披露上述本地处理。不要把“本地处理”描述成“完全不访问数据”。

确认数据仅用于已披露的单一功能，不出售，不用于广告或信用评估等无关用途。官网隐私政策包含对 Chrome 网上应用店用户数据政策及有限使用要求的明确说明。

## 审核人员测试步骤

1. 安装上传的 ZIP，打开任意公开 HTTP／HTTPS 网页。
2. 点击页码图标，确认完整 URL 自动填入且二维码出现。
3. 使用另一设备扫码，或将 PNG 下载后由二维码解码器读取，核对 URL。
4. 修改为中文文字，改变前景色、背景色和输出尺寸，确认预览变化。
5. 分别下载 PNG 和 SVG，检查尺寸与内容。
6. 关闭并重开弹窗，确认外观偏好保留，内容恢复为当前网页 URL。
7. 无需测试账号、密码、付费或远程服务。
